These were the instructions:

Create a new repository on GitHub (e.g. web-development-1).

Clone your repository to your computer. (git clone <your-repo-URL>)

Create Workshop1 folder inside it.

Open the repository folder in VS Code. (GitBash here and code .)

Create index.html and start coding.

Save your changes.

Commit and push your changes to GitHub.

Check on GitHub that your files are there.

Submit your GitHub repository link to Canvas.
